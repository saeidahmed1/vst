================================================================
  TASHREEQ VST - الحصول على الملف الجاهز للنسخ واللصق
  بدون تثبيت Visual Studio على جهازك (عبر GitHub مجاناً)
================================================================

1. ارفع محتويات هذا المجلد إلى مستودع جديد (New Repository) على GitHub.com.
2. اضغط على تبويب "Actions" في أعلى المستودع.
3. سيبدأ سيرفر ويندوز في GitHub ببناء الإضافة تلقائياً خلال ~4 دقائق.
4. عند انتهاء البناء (علامة صح خضراء)، انزل إلى قسم Artifacts وحمّل:
      Tashreeq-VST3-Ready-For-Mixcraft10
5. فك الضغط وستجد ملف الإضافة الجاهز للنسخ واللصق مباشرة:
      Tashreeq VST.vst3

----------------------------------------------------------------
النسخ إلى مجلد مخصص والاستيراد في Mixcraft 10:
----------------------------------------------------------------
1. انسخ "Tashreeq VST.vst3" إلى أي مجلد مخصص لديك (مثلاً C:\My_VSTs\).
2. في Mixcraft 10 افتح:
      File > Preferences > Plug-Ins > Edit VST/VSTi Folders
3. أضف مجلدك المخصص ثم اضغط OK واضغط Re-Scan All VST Plug-Ins.
4. ستظهر إضافة "Tashreeq VST" مباشرة ضمن الآلات الافتراضية!
